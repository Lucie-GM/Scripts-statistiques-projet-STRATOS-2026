# Scripts-statistiques-projet-STRATOS-2026
Ce dépôt contient les fichiers des codes statistiques employés pour analyser les données du projet STRATOS 2026 qui fait l'objet de mon mémoire de fin d'études : "Mise au point d'une stratégie de protection biologique intégrée pour lutter contre Drosophila suzukii en culture de fraise sous abri".
